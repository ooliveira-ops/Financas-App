# 💰 Finanças Filipe

App de controle de finanças pessoais com despesas, parcelamentos,
categorias e histórico de pagamentos.

🌐 **Site:** [financas-filipe.vercel.app](https://financas-filipe.vercel.app)

## ✨ Funcionalidades

- 🔐 **Cadastro por token** — acesso restrito por convite
- 💸 **Despesas** — pendentes, pagas, parceladas
- 📅 **Parcelamento** automático (ex: 4x R$200 vira 4 despesas mensais)
- ⚡ **Adiantar parcelas** — pague antecipadamente as que quiser
- 📊 **Histórico** completo de despesas pagas
- 🏷️ **Categorias** personalizáveis com cores e ícones
- 🔔 **Avisos** de contas vencendo ao abrir o app

## 🛠️ Tecnologias

- React + Vite 
- Tailwind CSS
- Supabase (banco de dados + autenticação)
- Hospedado na Vercel
